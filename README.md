# griphos
γρῖφος: a riddle, a puzzle, a net.

A rust/python package for modelling and solving electricity networks.

See [INSTALL.md](https://github.com/bsgip/griphos/blob/main/INSTALL.md) for installation instructions. See the [examples directory](https://github.com/bsgip/griphos/tree/main/examples) for some basic examples of using griphos within Rust. The documentation is [here](https://bsgip.github.io/griphos/griphos/).
