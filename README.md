# griphos
γρῖφος: a riddle, a puzzle, a net.

A rust/python package for modelling and solving electricity networks.

See [INSTALL.md](INSTALL.md) for installation instructions. See the [examples directory](./examples/) for some basic examples of using griphos within Rust.
